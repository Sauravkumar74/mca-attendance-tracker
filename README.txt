MCA Attendance Tracker — PSC corrected rebuild

The nine subjects are: PSC, C-LAB, COA, COA-LAB, DM, CS, FCET, POM, PC-LAB. C has been removed and PSC is included instead, as requested.
Known subject-code table mappings: C-LAB BMC-151; COA BMC-105; COA-LAB BMC-152; DM BMC-104; CS/Cyber Security BMC-106; FCET BMC-101; POM BMC-103; PC-LAB BMC-153. PSC full name/code was not clear in the shared image and is labelled unconfirmed.
Attendance percentage = Present/(Present+Absent). Leave is excluded. Minimum consecutive presents needed to reach 75% = max(0, 3*absences - presents). Estimate assumes every upcoming class is attended.
One-tap P/A/L, live overall/subject percentages, manual entries, log, JSON backup/restore, CSV export, local browser storage, and optional browser reminders are included.
The timetable PSC slots are tracked as PSC. Original timetable CS slots remain CS. Browser reminders are only checked while the page is open and aren't guaranteed if the browser is closed.
Open index.html in a modern browser. For installable/offline PWA support, host the files over HTTPS. Marks remain local to this browser/device.
