Calculation method

Attendance % = Present ÷ (Present + Absent). Leave is excluded. Minimum consecutive future classes needed to reach 75% = max(0, 3 × absences − presents). This assumes you attend every next class for that subject. Each tap recalculates the dashboard immediately.

All subjects & target calculator

Target: 75%
Exact math: with P present and A absent, adding n consecutive presents gives (P+n)/(P+A+n). The minimum n for 75% is max(0, 3A−P). If below 75%, this shows how many future classes must be attended in a row, assuming no more absences. Leave is excluded.
